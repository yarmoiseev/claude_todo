# To-do app

Let's build a to-do list web app. 
The main features: Snappy, simple, elegant, minimalist and, it should have responsive, mobile-first design. 

User should be able:
 - add a new task
 - edit task
 - delete task
 - assign priority (3-levels)
 - and move by dragging tasks to sort them (up and down)


Stack:
- TS and only TS (no vanilla JS)
- HTML components
- Tailwind
- Indexed DB for storage
- Eslint, Prettier
- Vite as a bundler
- (?) any techology or technologies of your choice, if you think that they are must and a good fit here.

The goal of the project:
- It's a CLAUDE CODE guided, study project which should help the developer learn this technologies and acquire new skills.
